Trust boundaries: Okta authenticates people; GitHub App credentials authorize repository operations; GitHub OIDC + GCP WIF authorize CI jobs. Interactive agents receive no GCP credentials. Tyk is the factory/MCP API gateway—not a replacement for cluster ingress.
