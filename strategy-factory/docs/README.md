# Enterprise Strategy Factory — Documentation

This directory contains the product baseline and implementation guidance for the Enterprise Strategy Factory (ESF).

## Documents

- [Product specification](product-specification.md) — vision, users, capabilities, requirements, guardrails, outcomes and MVP acceptance.
- [Target architecture](architecture/target-architecture.md) — logical components, information model, strategy lifecycle, integrations and trust boundaries.
- [Product experience and interaction design](design/product-experience-design.md) — navigation, screen behavior, interaction states, accessibility and prototype boundaries.
- [Implementation backlog](implementation-backlog.md) — sequenced delivery increments and validation criteria.

## Current prototype

The [interactive prototype](../index.html) is a standalone HTML experience with static examples and deterministic browser-side interactions. It does not connect to enterprise strategy, planning, financial, analytics or AI systems. The metrics, decisions, scenarios and outcomes shown in it are illustrative and must not be used as business evidence.

These documents describe a proposed product baseline. They are not evidence that the described services, controls, integrations or operating processes have been implemented.
